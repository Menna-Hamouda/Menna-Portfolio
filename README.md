# Menna Hamouda — Portfolio

A responsive personal portfolio for a Junior Front-End Developer. Built with semantic HTML, custom CSS, JavaScript, and the supplied Bootstrap 5 CSS/JS files.

## Included

- Responsive layout for desktop, tablet, and mobile
- Accessible navigation with a mobile menu
- About, skills, projects, education, and contact sections
- GitHub links for MHZ Store and MHZ Admin Dashboard
- LinkedIn and email links
- SEO description and Open Graph metadata
- Reduced-motion support and keyboard focus styles
- Custom teal, navy, off-white, and coral palette

## Run locally

1. Extract the ZIP file.
2. Open the `menna-portfolio` folder in VS Code.
3. Replace `assets/img/person.jpg` with your own portrait, keeping the exact filename and extension.
4. Open `index.html` in a browser, or use the VS Code Live Server extension.

Bootstrap files are included locally in `vendor/`.
